# 06 — Method Sources for the Core Course

**Date:** 2026-10-02. **Purpose:** the Core Course lessons teach methods and rules. This file lists every page that was opened to check a rule, what it actually says, and what it may be cited for. Standing rule from Hari: open the source, record the publisher and date, confirm it is the kind of page it claims to be, and state only what was observed. A search snippet, a tool's summary, or an HTTP 200 is not enough.

**How pages were read.** Static pages were downloaded and their text searched directly (`curl` plus a text extractor, so no model summary stands between me and the page). Pages that need JavaScript or refuse `curl` were read in the built-in browser or through a fetch tool that returns a summary; those are marked **(summary)** and used only for the specific sentences the summary quoted.

**What is not sourced here, on purpose.** Arithmetic, logic and pseudocode answers are not "sourced" from the web at all. They are verified by running code (brute force, exhaustive model search, real Java), which is stronger than citing a page. Web sources are cited only for *rules and conventions* (Java semantics, English grammar, the vocabulary of argument questions).
