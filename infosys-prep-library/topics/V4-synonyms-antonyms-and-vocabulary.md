## 3. Concept notes

### 3.1 The core idea

Every vocabulary question tests one of two skills: **recall** of a word's meaning, or **decomposition** of a word into prefix + root + suffix. If you know 40 prefixes and 40 roots, you can decode hundreds of words you have never consciously learned. That is the whole strategy. The word list matters less than the morpheme table.

### 3.2 Prefixes carry direction

| Prefix | Meaning | Example |
|---|---|---|
| **a- / an-** | without | amoral, anarchy |
| **ab-** | away | abduct |
| **ante-** | before | antedate |
| **anti- / contra-** | against | antipathy, contradict |
| **bene- / eu-** | good | benevolent, euphemism |
| **circum- / peri-** | around | circumvent, perimeter |
| **de-** | down, away | demote |
| **in- / im- / il- / ir-** | not | illegible, irreverent |
| **inter-** | between | intervene |
| **intra-** | within | intramural |
| **mal- / mis-** | bad, wrong | maladroit, misnomer |

Rule of thumb: **if the root is positive-coded (bene, phil, eu) the word is favourable; if negative-coded (mal, mis, phob) the word is unfavourable.** Tone often eliminates two options instantly.

### 3.4 Suffixes tell you the word class

| Suffix | Meaning | Example |
|---|---|---|
| **-cide** | killing | regicide |
| **-archy** | rule | monarchy |
| **-cracy** | power | bureaucracy |
| **-gamy** | marriage | monogamy |
| **-logy** | study of | etymology |
| **-ferous** | bearing | pestiferous |
| **-vorous** | eating | carnivorous |
| **-itis** | inflammation | bronchitis |
| **-phobia** | fear of | xenophobia |

### 3.5 Decoding a word you have never seen

Four steps, done in about ten seconds: split into prefix + root + suffix; assign each part a meaning; assemble the literal sense; match the literal sense to the closest option. Worked on **"incontrovertible"**: *in-* (not) + *contro* (against) + *vert* (turn) + *-ible* (able) = "not able to be turned against" = **indisputable**. The literal route gets you there even if the word is new.

### 3.7 Antonyms are the same list reversed

The antonym of a rare word is almost always the antonym of its common twin. *Frugal* is to *thrifty*, so the antonym is **extravagant**. *Laconic* is to *brief*, so the antonym is **verbose**. Build the habit: convert the rare word to its twin, then negate the twin. Negating the twin is faster than trying to recall the rare word's opposite directly.

### 3.8 Confusable pairs

| Pair | Distinction |
|---|---|
| **censor / censure** | censor = cut content; censure = formally criticise |
| **affect / effect** | affect = verb, to influence; effect = noun, result |
| **compliment / complement** | compliment = praise; complement = complete |
| **principal / principle** | principal = chief or head; principle = rule |
| **elicit / illicit** | elicit = draw out; illicit = illegal |
| **eminent / imminent** | eminent = distinguished; imminent = about to happen |
| **appraise / apprise** | appraise = value; apprise = inform |
| **adverse / averse** | adverse = unfavourable (thing); averse = disinclined (person) |
| **stationary / stationery** | stationary = still; stationery = writing materials |
| **allusion / illusion** | allusion = indirect reference; illusion = false perception |

### 3.9 One-word substitution, grouped

Person: **misanthrope** (hates mankind), **philanthropist** (loves mankind), **altruist** (selfless), **egoist** (self-centred), **stoic** (indifferent to pleasure and pain), **connoisseur** (expert judge of art), **polyglot** (speaks many languages), **somnambulist** (sleep-walker), **teetotaller** (never drinks alcohol), **misogynist** (hates women).

Thing: **extempore** (speech without preparation), **epitaph** (words on a tomb), **obituary** (notice of a death), **gullible** (easily deceived), **incorrigible** (cannot be corrected), **indefatigable** (never tires), **ubiquitous** (present everywhere), **omnipotent** (all-powerful), **omniscient** (all-knowing), **ephemeral** (short-lived).

| Phrase | Meaning |
|---|---|
| **to bell the cat** | to take the risk oneself |
| **to cut the Gordian knot** | to solve a difficulty by bold action |
| **to bury the hatchet** | to make peace |
| **to let the cat out of the bag** | to reveal a secret |
| **to smell a rat** | to suspect something wrong |
| **to bite the bullet** | to endure pain bravely |
| **to sit on the fence** | to stay neutral |
| **to eat humble pie** | to apologise humbly |
| **to pass the buck** | to shift responsibility |
| **a wild goose chase** | a hopeless search |

Phrasal verbs: **put off** = postpone; **call off** = cancel; **put up with** = tolerate; **give in** = surrender; **bring about** = cause; **do away with** = abolish; **take after** = resemble; **run out of** = exhaust.

## 4. Must-memorise block

**Decoding order: PREFIX -> ROOT -> SUFFIX -> literal sense -> match option.**

Negatives: **a-, an-, in-, im-, il-, ir-, dis-, un-, non-, mis-, mal-**
Direction: **ab-** away, **ad-** toward, **circum-** around, **trans-** across, **per-** through, **sub-** under, **super-** above
Value: **bene-, eu-, phil-** good | **mal-, mis-, phob-** bad

Roots to know cold: **cred** believe, **dict** speak, **duc** lead, **greg** flock, **loqu** speak, **luc** light, **mort** death, **path** feeling, **plac** please, **pug** fight, **spec** look, **tac** silent, **ver** truth, **voc** call.

**Antonym reflex - rare to twin, then negate:**
frugal -> thrifty -> **extravagant** | laconic -> brief -> **verbose** | candid -> frank -> **evasive** | benign -> kindly -> **malevolent** | ephemeral -> short-lived -> **permanent** | audacious -> bold -> **timid** | exacerbate -> worsen -> **mitigate** | taciturn -> silent -> **garrulous** | gregarious -> sociable -> **reclusive** | innocuous -> harmless -> **harmful** | magnanimous -> generous -> **petty** | parsimonious -> stingy -> **profligate** | equivocal -> ambiguous -> **unequivocal** | placid -> calm -> **agitated**

One-word substitutions: extempore, polyglot, stoic, connoisseur, misanthrope, misogynist, gullible, incorrigible, indefatigable, ubiquitous, omnipotent, omniscient, somnambulist, teetotaller, altruist.

Confusables: censor/censure, affect/effect, principal/principle, elicit/illicit, eminent/imminent, appraise/apprise, adverse/averse, stationary/stationery.

## 5. Worked examples

**Example 1 - Synonym.** Choose the word most similar in meaning to **OBSEQUIOUS**.
a) rebellious b) servile c) indifferent d) generous

Fast method: the suffix *-ous* makes it an adjective. Recall that *obsequious* describes someone who over-pleases. Answer: **b) servile**. The decoy is *rebellious*, which is the exact opposite and is placed first to catch a rushed negative-marking habit (there is none here, but it still catches speed-reading).

**Example 2 - Antonym.** Choose the word opposite in meaning to **GARRULOUS**.
a) talkative b) cheerful c) rude d) silent

Fast method: twin conversion. *Garrulous* = talkative. Negate the twin: not talkative = **d) silent**. Note that option (a) is the synonym, deliberately placed first. In an antonym question, always check whether the obvious match is the synonym, because it usually is.

**Example 3 - One-word substitution.** "One who is easily deceived" is:
a) credulous b) credible c) creditable d) incredulous

Fast method: all four share the root *cred* (believe). *Credible* = believable (about a thing). *Creditable* = praiseworthy. *Incredulous* = disbelieving. *Credulous* = too ready to believe, therefore easily deceived. Answer: **a) credulous**. This is the classic same-root trap; the root alone does not decide, the prefix and suffix do.

**Example 4 - Idiom.** "The manager decided to **bell the cat** and raise the audit issue himself." The bolded phrase means:
a) to avoid responsibility b) to warn others loudly c) to take the risk oneself d) to create confusion

Fast method: recall the fable - the mice agree to bell the cat but nobody volunteers, because it is the dangerous job. Meaning: **c) to take the risk oneself**. Taking idioms literally gives you "making a noise", which is option (b), the standard wrong answer.

**Example 5 - Analogy.** PARSIMONIOUS : MISER :: PRODIGAL : ?
a) spendthrift b) pauper c) miser d) borrower

Fast method: identify the relation. A *parsimonious* person behaves like a *miser* - the first word is the adjective, the second the person who embodies it to excess. *Prodigal* means recklessly wasteful; the person is a **spendthrift**. Answer: **a)**. The slow method - trying to define *prodigal* from memory before reading the options - wastes 30 seconds you do not have.

## 6. Traps and gotchas

| Trap | Why it catches people | How to avoid it |
|---|---|---|
| Antonym question answered with the synonym | The synonym is placed first in the options | Circle the word "opposite" in your head before reading options |
| Same-root decoy | *Incredible* vs *incredulous* look interchangeable | Match the suffix to the part of speech needed |
| Literal reading of an idiom | "Bell the cat" sounds like making noise | Idiom questions almost never take the literal sense |
| Confusable-pair swap | *Censure* and *censor* differ by one letter and both fit grammatically | Learn the pairs as minimal pairs, not separately |
| Choosing the familiar word | You pick the word you know rather than the one that is right | If two options are synonyms of each other, both are usually wrong |
| Tone guessing | A negative-sounding word is assumed to be the answer | Tone narrows choices but never decides alone |
| The exotic option | A rare word looks like the "exam" answer | Rare words are frequently the planted distractor |
| Burning time | Trying to recall an unknown word instead of decoding it | Cap at 45 seconds, then decode by prefix and root |

## 7. Practice questions

1. Choose the word most similar in meaning to **CANDID**. a) deceptive b) reluctant c) frank d) harsh

2. Choose the word opposite in meaning to **FRUGAL**. a) extravagant b) thrifty c) cautious d) modest

3. "A speech delivered without preparation" is: a) eulogy b) soliloquy c) rhetoric d) extempore

4. The prefix in **CIRCUMVENT** means: a) against b) around c) before d) under

5. The idiom **to bell the cat** means: a) to take the risk oneself b) to warn others loudly c) to make a lot of noise d) to avoid danger

6. Choose the correct word: "The committee decided to ______ the report before publishing it." a) censure b) sensor c) censor d) censer

7. Choose the word most similar in meaning to **LACONIC**. a) verbose b) brief c) cheerful d) bitter

8. The idiom **to cut the Gordian knot** means: a) to make a problem worse b) to avoid a decision c) to untangle something slowly d) to solve a difficulty by bold action

9. "One who speaks many languages" is: a) polyglot b) linguist c) bilingual d) orator

10. Choose the word opposite in meaning to **PROFLIGATE**. a) wasteful b) generous c) lavish d) frugal

11. PARSIMONIOUS : GENEROUS :: TIMID : ? a) afraid b) bold c) weak d) slow

12. "The evidence was so ______ that the jury returned a verdict within ten minutes." a) ambiguous b) tedious c) unequivocal d) plausible

### ANSWER KEY

1. **c** - *Candid* means open and straightforward, i.e. frank.
2. **a** - *Frugal* means thrifty, so its opposite is extravagant.
3. **d** - *Extempore* is speech delivered without preparation.
4. **b** - *Circum-* means around; *vent* comes from *venire*, to come.
5. **a** - The fable's point is that nobody volunteers for the dangerous job, so it means taking the risk oneself.
6. **c** - *Censor* means to cut or suppress content; *censure* means to criticise formally.
7. **b** - *Laconic* means using very few words, i.e. brief.
8. **d** - Alexander cut the knot rather than untying it, meaning a bold, decisive solution.
9. **a** - *Polyglot* combines *poly-* (many) and *glot* (tongue/language).
10. **d** - *Profligate* means recklessly wasteful, so its opposite is frugal.
11. **b** - The relation is antonym pairs in order, so the opposite of timid is bold.
12. **c** - A ten-minute verdict implies clear evidence, so *unequivocal* (leaving no doubt) fits.
