# Aptitude — what to study and in what order

The aptitude block is **Reasoning Ability (15 Q, 25 min) + Technical Ability (10 Q, 35 min)**: 25 marks. Sources disagree on which topic sits in which half, so this library prepares them as one 25-question block. If you have already done the L&T aptitude (the topic files copied here from that library), skip the files marked **copied** and spend the time on those marked **new**.

Three method guides cover the whole of aptitude and verbal; read the one for your weakest block first:

- [Quant from zero](00-QUANT-FROM-ZERO.md) · [Logical from zero](00-LOGICAL-FROM-ZERO.md) · [Verbal from zero](00-VERBAL-FROM-ZERO.md)
