  2. c — Eliminate one variable (multiply and subtract): x = 14, y = -7. So x > y.
  3. a — 36 − 4 = 32; 60 + 3 = 63. Ratio 32 : 63 = 32:63.
  4. b — 24 − 2 = 22; 40 + 3 = 43. Ratio 22 : 43 = 22:43.
  5. d — Solve the pair: a pen costs ₹3, a pencil ₹9. Then 5×3 + 2×9 = ₹33.
  6. b — 18 − 4 = 14; 30 + 3 = 33. Ratio 14 : 33 = 14:33.
  7. a — Suppose all 44 are bikes: 44 × 2 = 88. The extra 54 comes from cars, each adding 2. So cars = 54/2 = 27.
  8. c — Suppose all 39 are bikes: 39 × 2 = 78. The extra 48 comes from cars, each adding 2. So cars = 48/2 = 24.
  9. c — The middle/average term is 50/4 = 12.5. The numbers are 11, 12, 13, 14, so the largest is 14.
  10. b — Suppose all 31 are goats: 31 × 4 = 124. The excess 18 comes from ducks, each over-counted by 2. So ducks = 18/2 = 9.
  11. d — Eliminate one variable (multiply and subtract): x = -15, y = -19. So x > y.
  12. c — Solve the pair: a pen costs ₹6, a pencil ₹3. Then 4×6 + 1×3 = ₹27.
  13. d — The middle/average term is 105/3 = 35. The numbers are 34, 35, 36, so the smallest is 34.
  14. c — 30 − 2 = 28; 45 + 4 = 49. Ratio 28 : 49 = 4:7.
  15. a — 48 − 4 = 44; 72 + 2 = 74. Ratio 44 : 74 = 22:37.
  16. d — The middle/average term is 90/5 = 18. The numbers are 14, 16, 18, 20, 22, so the smallest is 14.
  17. a — Eliminate one variable (multiply and subtract): x = 52, y = 20. So x > y.
  18. c — Suppose all 40 are ducks: 40 × 2 = 80. The extra 44 comes from goats, each adding 2. So goats = 44/2 = 22.
  19. c — Eliminate one variable (multiply and subtract): x = 21, y = -15. So x > y.
  20. a — Eliminate one variable (multiply and subtract): x = 21, y = -17. So x > y.
  21. a — The middle/average term is 96/3 = 32. The numbers are 30, 32, 34, so the smallest is 30.
  22. b — Eliminate one variable (multiply and subtract): x = 5, y = 57. So x < y.
  23. a — Suppose all 28 are stools: 28 × 3 = 84. The extra 17 comes from tables, each adding 1. So tables = 17/1 = 17.
  24. b — Suppose all 20 are ducks: 20 × 2 = 40. The extra 28 comes from goats, each adding 2. So goats = 28/2 = 14.
