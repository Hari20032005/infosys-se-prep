30. [Average of positions] In a certain code FRAUD is written as 10 and BURST as 16. What is the code for ENGINE? a) 10 b) 9 c) 54 d) 8

ANSWER KEY

  1. d — The code is the average of the letter positions. ENGINE: 54 ÷ 6 = 9; CASTLE: 60 ÷ 6 = 10. TABLE: 40 ÷ 5 = 8.
  2. a — Compare CREATE with GVCGTE: the word is written backwards and every letter then moves 2 places forward in the alphabet. HAMMER reversed is REMMAH; shifting each letter gives TGOOCJ.
  3. b — Only the positions change: letter 1 goes to place 2, letter 2 goes to place 1. Apply the same shuffle to BURST: UBRST.
  4. a — ‘sun’ is the only word common to both sentences, and the only code common to both is za. So sun = za.
  5. a — Compare the code with the word letter by letter: even positions keep the alphabet number and odd positions become 0. BURST → 0210190. Apply it to RIVER: R=0 I=9 V=0 E=5 R=0 → 09050.
  6. d — Each letter stands for its place in the alphabet and the code is the sum. BREAK: 2 + 18 + 5 + 1 + 11 = 37; NORTH: 14 + 15 + 18 + 20 + 8 = 75. So BRAVE = 2 + 18 + 1 + 22 + 5 = 48.
  7. b — Compare the code with the word letter by letter: even positions keep the alphabet number and odd positions become 0. CLOUD → 0120210. Apply it to GUITAR: G=0 U=21 I=0 T=20 A=0 R=18 → 021020018.
  8. d — Each letter stands for its place in the alphabet and the code is the sum. LIGHT: 12 + 9 + 7 + 8 + 20 = 56; WATER: 23 + 1 + 20 + 5 + 18 = 67. So OCEAN = 15 + 3 + 5 + 1 + 14 = 38.
  9. a — Only the positions change: letter 1 goes to place 3, letter 3 goes to place 1. Apply the same shuffle to STONE: OTSNE.
  10. b — Only the positions change: letter 3 goes to place 4, letter 4 goes to place 3. Apply the same shuffle to SMART: SMRAT.
  11. c — The code is the average of the letter positions. NORTH: 75 ÷ 5 = 15; CASTLE: 60 ÷ 6 = 10. BURST: 80 ÷ 5 = 16.
  12. c — The code is the average of the letter positions. ENGINE: 54 ÷ 6 = 9; FRAUD: 50 ÷ 5 = 10. CLOUD: 55 ÷ 5 = 11.
  13. d — The code is the average of the letter positions. NORTH: 75 ÷ 5 = 15; TABLE: 40 ÷ 5 = 8. CLOUD: 55 ÷ 5 = 11.
  14. a — Only the positions change: letter 1 goes to place 2, letter 2 goes to place 1. Apply the same shuffle to ZEBRA: EZBRA.
  15. d — ‘sun’ is the only word common to both sentences, and the only code common to both is ne. So sun = ne.
  16. a — Compare the code with the word letter by letter: even positions keep the alphabet number and odd positions become 0. TIGER → 09050. Apply it to FRUIT: F=0 R=18 U=0 I=9 T=0 → 018090.
  17. a — ‘sun’ is the only word common to both sentences, and the only code common to both is pu. So sun = pu.
  18. d — Compare MOUSE with CQSMK: the word is written backwards and every letter then moves 2 places back in the alphabet. HAMMER reversed is REMMAH; shifting each letter gives PCKKYF.
  19. b — The code is the average of the letter positions. LAST: 52 ÷ 4 = 13; CLOUD: 55 ÷ 5 = 11. BURST: 80 ÷ 5 = 16.
  20. b — Only the positions change: letter 1 goes to place 5, letter 5 goes to place 1. Apply the same shuffle to BRIEF: FRIEB.
  21. c — ‘rain’ is the only word common to both sentences, and the only code common to both is to. So rain = to.
  22. c — The code is the average of the letter positions. FRAUD: 50 ÷ 5 = 10; NORTH: 75 ÷ 5 = 15. CLOUD: 55 ÷ 5 = 11.
  23. c — Compare the code with the word letter by letter: odd positions keep the alphabet number and even positions become 0. TIGER → 2007018. Apply it to SMART: S=19 M=0 A=1 R=0 T=20 → 1901020.
  24. a — The code is the average of the letter positions. CASTLE: 60 ÷ 6 = 10; CLOUD: 55 ÷ 5 = 11. TABLE: 40 ÷ 5 = 8.
  25. c — Only the positions change: letter 1 goes to place 2, letter 2 goes to place 1, letter 3 goes to place 4, letter 4 goes to place 3. Apply the same shuffle to TIGER: ITEGR.
  26. b — Each letter stands for its place in the alphabet and the code is the sum. GUITAR: 7 + 21 + 9 + 20 + 1 + 18 = 76; ZEBRA: 26 + 5 + 2 + 18 + 1 = 52. So HOUSE = 8 + 15 + 21 + 19 + 5 = 68.
  27. d — Compare the code with the word letter by letter: odd positions keep the alphabet number and even positions become 0. WATER → 23020018. Apply it to MARKET: M=13 A=0 R=18 K=0 E=5 T=0 → 13018050.
  28. c — Each letter stands for its place in the alphabet and the code is the sum. VOICE: 22 + 15 + 9 + 3 + 5 = 54; CASTLE: 3 + 1 + 19 + 20 + 12 + 5 = 60. So CHAIR = 3 + 8 + 1 + 9 + 18 = 39.
  29. b — Compare FRAUD with CTZQE: the word is written backwards and every letter then moves 1 place back in the alphabet. JUNGLE reversed is ELGNUJ; shifting each letter gives DKFMTI.
  30. b — The code is the average of the letter positions. FRAUD: 50 ÷ 5 = 10; BURST: 80 ÷ 5 = 16. ENGINE: 54 ÷ 6 = 9.
