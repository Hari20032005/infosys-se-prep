QB-98 — The official sample paper, solved

Source: Infosys's own sample test for Systems Engineer, a PDF made by Infosys Ltd in September 2020: open the PDF. Open it beside this file; the question numbers below are the PDF's own.

What this is. 54 questions in five timed sections (Reasoning 25 min, Technical 35 min, Verbal 20 min, Pseudocode 10 min, Puzzle 10 min). It is the only first-party sample question paper I could find for this exam, which is why it ranks above every video and blog in this library (see ../research/05-source-credibility.md).

What this is not. - It is a 2020 sample with five sections. The 2027-batch test is reported to have seven. Treat it as the best evidence of question style, not of the current section counts. - The PDF has a CONFIDENTIAL watermark although it sits at a public address. So this file links to it and gives only a paraphrased gist of each question plus my own answer and working. Nothing is copied. - The PDF has no answer key. Every answer here was worked out for this library, not copied from anywhere.

How each answer was decided (31 by running code · 21 by judgement · 2 not solved): - decided by running code: brute force over the real constraints, a simulation, or a model search. Re-run it with python3 data/official_sample.py; it exits non-zero if any check fails. - judgement: verbal and unit-reasoning items. These are the least certain answers in the library, so read the reason, not just the letter. - NOT SOLVED: the two multi-select deduction items. They never say which triples count as "related", and the key is not published, so no answer is invented.

Two answers deserve a warning. Deductive items 3 to 5 (O13 to O15 here) are answered on the reading that the first two statements must entail the third; on a looser reading the answer to O15 changes. The code states both readings.

O14 · deductive reasoning · question 4

  • Asks (paraphrased): Painters, farmers, choreographers: which triple is logically related?

O15 · deductive reasoning · question 5

  • Asks (paraphrased): Fishes, swimmers, carnivorous: which triple is logically related?
  • Answer: d (none of the above)
  • Why: On the reading that the first two statements must entail the third, none of DCB, EDA, BEC works (B and C entail E, but BEC puts E second). On an unordered reading BEC would be the answer; the official key is not published
  • How decided: decided by running code · topic A4
